# Little Shloka Adventures

Create a responsive website called Little Shloka for children aged 4–10 years to learn simple Sanskrit shlokas and mantras.

The website should have a beautiful, minimalist, child-friendly design inspired by modern educational apps. Use a soft ivory background, pastel sage green, lavender and muted yellow. Use rounded cards, large readable typography and charming original illustrations.

Create these pages:

- Home

- Shloka Library

- Individual Shloka

- Games

- About

On the home page, display a welcome message, a featured shloka, a prominent Listen and Learn button and colourful cards for different learning categories.

Make the design responsive for mobile phones, tablets and desktops. Use simple navigation and large buttons suitable for young children.

Initially, use sample shlokas and placeholder audio. Do not add user registration, payments or complex features yet.
